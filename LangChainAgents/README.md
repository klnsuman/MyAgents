# LangChainAgents

A new project for building LangChain-based agent examples.

## Quick start

1. Create a virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the sample:
   ```bash
   python main.py
   ```

## Project structure

- `main.py` - simple LangChain agent example
- `requirements.txt` - project dependencies
- `.gitignore` - files to ignore
